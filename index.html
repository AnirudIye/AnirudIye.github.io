02 / WORK

Things I have shipped

FootyBoard screenshot

FootyBoard

live ↗

A soccer tactics board two people can use at once. Send someone a link and they land on the same pitch, cursor and all, with every token move synced as it happens.

There is an assistant docked in the corner that can read the board. You type "set the away team in a mid-block 4-4-2" and watch it move the pieces.

  • React 19
  • TypeScript
  • Konva
  • Postgres
  • Vite
BetterDresser screenshot

BetterDresser

live ↗

Photograph your clothes and it tags them. From there it picks outfits against the weather, your calendar, and whatever dress code the day calls for. You can also point a camera at yourself and see a piece on before buying it.

Every external service in it is optional. Pull out the API keys and the app still runs on fallbacks, which is the part I am most pleased with.

  • FastAPI
  • React
  • SQLAlchemy
  • Stripe
  • Claude vision
