02 / WORK

Shipped projects

FootyBoard screenshot

FootyBoard

live ↗

A collaborative tactics board for soccer. Two people open the same link and work on one pitch, with cursors and token positions synchronised in real time.

An assistant docked on the canvas reads the board state and edits it from plain language. Typing "set the away team in a mid-block 4-4-2" repositions the players.

  • React 19
  • TypeScript
  • Konva
  • Postgres
  • Vite
BetterDresser screenshot

BetterDresser

live ↗

A wardrobe application that catalogues clothing from photographs, then recommends outfits against the forecast, the day's calendar entries, and any dress code attached to them. A camera try-on renders a garment on the wearer before purchase.

Every external service is optional. With no API keys configured the application still runs on deterministic fallbacks rather than failing, which is the part of it I am most pleased with.

  • FastAPI
  • React
  • SQLAlchemy
  • Stripe
  • Claude vision
